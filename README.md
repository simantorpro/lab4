## О скрипте

Bash-скрипт `student_analyzer.sh` для работы с файловой системой преподавателя из ЛР №3 (`labfiles-3-26`).

Реализованы все требуемые функции:

| Команда | Что делает | Требование |
|---------|------------|------------|
| `longest <группа>` | Студент(ы) с самой длинной фамилией | FR-01 |
| `missed <группа>` | Номера пропущенных занятий по каждому студенту | FR-02 |
| `avg <группа> [группа...]` | Средняя посещаемость | FR-03 |
| `dossier <имя>` | Показать досье студента | FR-04 |
| `delete <имя>` | Удалить только досье (с подтверждением) | FR-05 |

---

## Как запустить

```bash
# Перейти в папку со скриптом
cd lab4-solution

# Справка
bash student_analyzer.sh help

# Примеры
bash student_analyzer.sh longest A-06-04
bash student_analyzer.sh missed A-06-23
bash student_analyzer.sh avg A-06-04 A-06-05
bash student_analyzer.sh dossier KarpovaVG
bash student_analyzer.sh delete KarpovaVG
```

### Путь к данным

По умолчанию скрипт ищет данные здесь:

```
../labfiles-3-26
```

То есть ожидается такая структура:

```
какая-то-папка/
├── labfiles-3-26/          ← данные из ЛР3
└── lab4-solution/
    └── student_analyzer.sh
```

Можно указать другой путь:

```bash
bash student_analyzer.sh --data-dir /полный/путь/к/labfiles-3-26 longest A-06-04
```

или через переменную окружения:

```bash
export DATA_DIR=/полный/путь/к/labfiles-3-26
bash student_analyzer.sh longest A-06-04
```

## Описание команд

### 1. `longest <группа>`
Находит студента с самой длинной **фамилией**.

- Если несколько студентов с одинаковой максимальной длиной — выводятся все.

```bash
bash student_analyzer.sh longest A-06-04
```

### 2. `missed <группа>`
Показывает номера пропущенных занятий (где стоит `0`) по каждому предмету.

```bash
bash student_analyzer.sh missed A-06-04
```

### 3. `avg <группа> [группа...]`
Считает среднюю посещаемость.

Формула:  
`(количество единиц) / (общее количество отметок) × 100%`

Считается суммарно по обоим предметам.

```bash
bash student_analyzer.sh avg A-06-04
bash student_analyzer.sh avg A-06-04 A-06-05
```

### 4. `dossier <имя>`
Выводит досье студента из заметок преподавателя.

```bash
bash student_analyzer.sh dossier KarpovaVG
```

### 5. `delete <имя>`
Удаляет **досье** студента.

- Перед удалением нужно ввести `YES`.
- Создаётся резервная копия файла (`.bak`).

```bash
bash student_analyzer.sh delete KarpovaVG
```

## Обработка ошибок

- Нет группы / файла → сообщение
- Пустой ввод → справка
- Удаление без `YES` → отмена, данные не трогаются
- Операции чтения не меняют исходные файлы

---

## Замечания

- После удаления рядом с файлом появляется `.bak`.
- Команда `longest` работает только для групп, у которых есть файл в `students/groups/`.
- Команды `missed` и `avg` работают и без файла группы (только по attendance).
